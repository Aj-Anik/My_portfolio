# Kazi Abu Jafar Anik | Portfolio

Personal portfolio of **Kazi Abu Jafar Anik**, a Computer Science and Engineering student at International Islamic University Chittagong (IIUC). The site is styled like a Linux tiling desktop: slate window panels, a monospace font, and powerline-style prompts.

### Languages

- **TypeScript** (TSX): components, data, and hooks
- **HTML**: page shell, metadata, and structured data (`index.html`)
- **CSS**: global styles and design tokens, written through Tailwind CSS
- **JavaScript**: build helper script (`scripts/inject-fonts.mjs`)

### Frameworks and libraries

| Area | Tools |
|---|---|
| UI framework | React |
| Build tool | Vite |
| Styling | Tailwind CSS |
| Animation | Motion |
| Icons | Lucide React |
| Font | JetBrains Mono (self-hosted) |
| Hosting | Vercel |
